## 🎯 About This Room

This room introduced me to the fundamentals of offensive security through a hands-on simulated banking application called FakeBank.

Instead of only learning theoretical concepts, I worked inside a virtual Linux desktop, explored a web application, discovered hidden pages and completed a simulated security exercise.

## 🧪 Practical Tasks Performed

### 1. Exploring the Virtual Environment
- Launched the TryHackMe virtual desktop.
- Opened Firefox and accessed the simulated FakeBank application.
- Explored the application's interface and functionality.

### 2. Discovering Hidden Pages
- Opened the Linux terminal.
- Used **Dirb**, a web content scanner, to discover hidden directories and pages.
- Examined the scan output to identify accessible web paths.

### 3. Exploring the Admin Page
- Used the discovered page to access the simulated administrative functionality.
- Followed the room's instructions to complete the banking application exercise.
- Verified that the simulated account balance had changed successfully.
